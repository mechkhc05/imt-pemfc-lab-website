# Phase 1 결과 정리 — Baseline 재현 & PINN

이 문서는 향후 논문 작성을 위한 근거 자료로, 지금까지 진행한 내용과 결과를
빠짐없이 정리한 것입니다. 재현 가능하도록 실행 명령과 코드 위치도 함께
기록합니다.

## 1. 프로젝트 목표

25 cm² (5×5 cm) PEMFC의 온도·압력·습도·화학양론비 등 다양한 운전조건에서
I-V 곡선과 출력(전력밀도, 시스템효율, 산소분포균일도)을 예측하는 모델을
만드는 것이 목표. 최종적으로는:

1. CFD(Ansys) 데이터 + 물리 법칙을 결합한 **PINN**으로, 적은 CFD 케이스로도
   넓은 운전조건 범위를 신뢰성 있게 예측
2. PINN이 만든 데이터로 **DeepONet**을 학습해 실시간 추론
3. **Unity**로 실시간 시각화
4. 논문 작성

이 문서는 1번(PINN) 단계까지의 결과를 다룹니다.

## 2. 데이터

### 2.1 CFD 데이터셋 — `data/raw/dataset_formodel_paper2-3.xlsx`

306행 = 51개 운전조건 조합 × 전압 6단계(0.4~0.9V, 0.1V 간격).

| 입력 변수 | 값 |
|---|---|
| Pressure (atm) | 1, 2, 3 |
| Anode/Cathode temperature (°C) | 50, 70, 80, 90, 100 |
| Anode/Cathode humidity (%RH) | 20, 60, 80, 100 |
| Anode stoichiometry | 1, 3, 5 |
| Cathode stoichiometry | 1.5, 3.5, 5.5 |
| Voltage (V) | 0.4 ~ 0.9 |

출력 변수: `current` (A/cm²), `power density` (W/cm², = current×voltage),
`System efficiency`, `stand devision o2` (O₂ 분포 표준편차, 낮을수록 균일).

**참고**: 랩에서 발표한 논문(아래 2.2)의 Table 4는 압력 조건을 "1, 3, 5
atm"으로 기술하는데, 이 엑셀은 "1, 2, 3"으로 되어 있어 정확히 같은
데이터셋은 아닙니다(파일명의 "paper2-3"가 시사하듯, 후속 논문을 위해
확장/변경된 데이터셋으로 보입니다). 전체 구조와 변수명은 논문과 동일합니다.

### 2.2 참고 논문

Ngo, Nguyen, Lee, Kim, "Comparative analysis and evaluation of PEMFC machine
learning surrogates by bridging CFD and experimental data", *J. Ind. Eng.
Chem.* (2025). https://doi.org/10.1016/j.jiec.2025.10.027

- ANSYS Fluent 3D CFD (연속/운동량/에너지/종보존/용존수/양성자·전자 전달)
- 100kPa, 300kPa 두 조건에서 실측 분극곡선으로 CFD 모델 검증
- RF/GB/SVM/ANN/XGBoost 대리모델 비교, Optuna로 하이퍼파라미터 튜닝(20 trial,
  TPE), 80/20 split, 5-fold CV
- **핵심 결과**: XGBoost 최고 성능 — PD R²=0.9891, SE R²=0.9989, ODU R²=0.9355
- **논문이 스스로 밝힌 한계**: "295개는 넓은 운전영역 대비 부족한 데이터이며,
  ANN/SVM 등은 더 많은 데이터가 있으면 개선될 것" → 이 프로젝트(PINN)의
  출발점

### 2.3 실험 I-V 데이터 — `data/raw/0kpa_I-V_curve.xlsx`

연구실에서 직접 측정한 분극곡선. 조건: **70°C, 0kPa(게이지, ≈1 atm), 면적
5cm²**, 습도 100%, 화학양론비 3.5 (사용자 확인). 전압 0.95~0.35V, 2회 반복
측정(1st/2nd), 총 22개 유효 포인트(전류 0인 OCV 포인트 2개 제외).

## 3. 방법론

### 3.1 Baseline 재현 — `src/baseline_reproduce.py`

논문과 동일한 입력 8개(Pressure, AT, AH, AS, CT, CH, CS, Voltage) → 출력
3개(PD, SE, ODU)로, RF/GB/SVR/ANN/XGBoost를 학습(Optuna 튜닝 없이 기본
하이퍼파라미터 사용, 80/20 split, random_state=62).

### 3.2 실험 데이터로 물리식 검증 — `src/fit_experimental_iv.py`

PEMFC 표준 반경험적 분극곡선 방정식:

```
V = E_Nernst(T,P) − η_activation(i,T) − η_ohmic(i,T,RH) − η_concentration(i,P,stoi,RH)

E_Nernst = 1.229 − 0.85e-3·(T−298.15) + (RT/2F)·ln(P_H2·√P_O2)
η_activation = (RT/αF)·ln(i/i0)
η_ohmic = i·R_ohm
η_concentration = −B·ln(1 − i/i_lim)
```

E_Nernst는 표준 상수(E0=1.229V, Nernst 온도계수 0.85mV/K)로 고정하고,
나머지 5개 계수(α, i0, R_ohm, B, i_lim)를 실험 데이터(2.3)에 비선형
최소제곱법(`scipy.optimize.curve_fit`)으로 피팅.

### 3.3 PINN 설계 — `src/pinn/`

- **`CurrentNet`**: 8개 운전조건 → 전류밀도 i를 예측하는 MLP (64-64-64
  hidden). CFD 데이터(전류) 손실 + 물리 손실(예측한 i를 위 방정식에 넣었을
  때 나오는 전압이 입력 전압과 일치해야 함) 로 학습.
- **`PolarizationPhysics`**: 위 방정식의 계수 함수. 처음엔 각 계수(i0,
  R_ohm, i_lim)를 16유닛 MLP로 만들었으나(파라미터 900개+), 데이터가 적을 때
  전혀 안정적으로 안 배워져서, **저파라미터 물리식**으로 교체(총 11개
  스칼라 파라미터):
  - `i0(T) = exp(ln(i0_ref) − (Ea/R)·(1/T − 1/T_ref))` — Arrhenius형, 2개
    파라미터. **실험 데이터로 앵커링하지 않음** — 단일 조건 실험으로는 α와
    i0가 서로 상쇄되어(트레이드오프) 식별 불가능했기 때문에(아래 3.2 결과
    참고), CFD의 5개 온도 조건으로부터 학습.
  - `α`(활성화 전달계수), `R_ohm(T,RH)`, `B`(농도손실계수),
    `i_lim(P,stoi_c,RH)` — 각각 실험 피팅값으로 **초기화 + 앵커링 손실**
    적용(그 조건에서 실험값과 크게 벗어나면 페널티), 나머지는 CFD 데이터로
    조정.
- **PD**: 전류×전압으로 정확히 계산 (별도 학습 불필요, 논문 식 그대로)
- **SE, ODU**: 닫힌 형태 수식이 마땅치 않아 데이터 기반 소형 MLP 헤드로 예측
  (물리 제약 없음, 대신 물리적으로 일관된 전류 예측값을 입력 특징으로 받음)

## 4. 결과

### 4.1 Baseline 재현 — 논문 수치와 비교

Optuna 튜닝 없이도 XGBoost/GB/RF는 논문과 거의 일치. ANN은 튜닝이 없어 논문보다
크게 낮음(하이퍼파라미터 탐색이 실제로 중요했다는 뜻이기도 함).

| 모델 | PD R² (재현/논문) | SE R² (재현/논문) | ODU R² (재현/논문) |
|---|---|---|---|
| XGBoost | 0.9881 / 0.9891 | 0.9986 / 0.9989 | 0.9209 / 0.9355 |
| Gradient Boosting | 0.9864 / 0.9846 | 0.9994 / 0.9989 | 0.9142 / 0.9259 |
| Random Forest | 0.9808 / 0.9699 | 0.9959 / 0.9968 | 0.8547 / 0.8512 |
| SVR/SVM | 0.9631 / 0.9505 | 0.9479 / 0.9850 | 0.8291 / 0.8421 |
| ANN | 0.8365 / 0.9742 | 0.9306 / 0.9980 | 0.7416 / 0.9136 |

### 4.2 실험 데이터로 물리식 검증

22개 실측 포인트(70°C, ~1atm, RH100%, stoi 3.5) 피팅 결과:

| 계수 | 피팅값 | 비고 |
|---|---|---|
| α (전달계수) | 1.2085 | 두 번의 독립 피팅에서 일관되게 재현됨 → 신뢰도 높음 |
| R_ohm (면적저항) | 0.0235 Ω·cm² | 문헌상 일반적인 Nafion 막 저항 범위 내 |
| B (농도손실계수) | 0.1911 V | 신뢰도 높음 |
| i_lim (한계전류밀도) | 1.7419 A/cm² | 신뢰도 높음 (측정 최대전류 1.48 A/cm²보다 커야 하는데 부합) |
| i0 (교환전류밀도) | 식별 불가 (경계로 발산) | E_Nernst를 이론값으로 고정하면 α와 트레이드오프되어 단일 조건 데이터로는 못 정함 |

**피팅 정확도: R²=0.99962, RMSE=3.07mV** — 방정식 형태 자체가 실측 분극곡선을
매우 정확하게 재현. 물리 모델 선택이 타당했다는 강한 근거.

### 4.3 PINN 전체 데이터 학습 (baseline과 동일 80/20 split)

| 출력 | PINN R² | PINN RMSE | (참고) XGBoost R²/RMSE |
|---|---|---|---|
| current | 0.9919 | 0.0603 | — (baseline은 PD/SE/ODU만 직접 예측) |
| power density | 0.9864 | 0.0355 | 0.9881 / 0.0332 |
| System efficiency | 0.9991 | 0.0057 | 0.9986 / 0.0072 |
| stand devision o2 | 0.8978 | 0.3178 | 0.9209 / 2.795e-1 |

전체 데이터에서는 PINN과 XGBoost가 대등한 수준.

학습된 물리 계수(앵커 조건에서 재확인): α=1.2078(실험 1.2085와 거의 동일),
R_ohm=0.1434(실험 0.0235에서 6배 증가 — CFD 데이터가 강하게 밀어냄), B=0.1927,
i_lim=1.7403(실험값과 거의 동일). R_ohm이 크게 벗어난 것은 두 데이터
소스(CFD vs 실험) 간 조건 불일치 가능성(2.1의 압력 범위 불일치 등)을 시사 —
추후 조사 필요.

### 4.4 데이터 효율성 비교 (보간 — random train/test split)

같은 고정 테스트셋에서, 학습 데이터양을 줄여가며 비교. **보간 문제에서는
XGBoost가 전 구간에서 우세** — 트리 기반 모델이 원래 작은 정형 데이터에서
신경망보다 표본 효율이 좋다는 잘 알려진 현상.

| 학습 샘플 수 | XGBoost R² | PINN R² |
|---|---|---|
| 24 (10%) | 0.8789 | 0.8159 |
| 48 (20%) | 0.9111 | 0.8933 |
| 97 (40%) | 0.9608 | 0.9514 |
| 146 (60%) | 0.9796 | 0.9587 |
| 195 (80%) | 0.9852 | 0.9725 |
| 244 (100%) | 0.9883 | 0.9795 |

### 4.5 외삽(extrapolation) 비교 — 핵심 검증

**이게 이 프로젝트의 진짜 가설**입니다: CFD를 안 돌린 조건(훈련 범위 밖)도
믿을 만하게 예측하는가. 각 축의 극단값 하나를 통째로 학습에서 빼고, 그
조건만 테스트 (전력밀도 예측 기준):

| 외삽 조건 | 훈련/테스트 개수 | XGBoost R² | PINN R² | 승자 |
|---|---|---|---|---|
| **전압 0.4V (최저, 농도손실 지배 구간)** | 255/51 | 0.6645 | **0.7733** | **PINN** |
| 압력 3atm (최고) | 198/108 | **0.8825** | 0.8253 | XGBoost |
| 습도 20% (최저, 건조/고저항 구간) | 252/54 | **0.9469** | 0.6527 | XGBoost |
| 애노드 화학양론비 1 (최저, 연료부족 구간) | 204/102 | **0.7364** | 0.6104 | XGBoost |
| 캐소드 화학양론비 1.5 (최저) | 204/102 | **0.9157** | 0.8952 | XGBoost |
| 애노드 온도 100°C (최고) | 258/48 | **0.9733** | 0.9272 | XGBoost |

**해석**: 전압을 벗어난 외삽에서는 PINN이 뚜렷하게 우세(XGBoost는 훈련 범위
밖으로 나가면 R²가 0.988→0.664로 급격히 무너지는 반면, PINN은 0.980→0.773로
상대적으로 완만하게 저하). 이는 전압이 분극곡선 방정식이 **직접, 정확한
로그함수 형태로** 다루는 축이기 때문으로 보입니다.

반면 온도·압력·습도·화학양론비 축에서는 아직 XGBoost가 앞섭니다. 이 축들에
대한 물리 계수의 의존성(현재는 Arrhenius 또는 단순 선형 보정)이 실제 비선형
거동(예: 막 전도도의 습도 의존성은 문헌상 훨씬 비선형적/S자형)을 충분히
담아내지 못했기 때문으로 추정 — **다음 개선 지점**입니다.

## 5. 결론 및 다음 단계

- 분극곡선 방정식 자체는 실측 데이터로 강하게 검증됨(R²=0.9996)
- 보간 성능은 XGBoost와 대등
- **전압 축 외삽에서는 PINN이 확실히 우세** — 물리 제약이 실제로 도움이 된다는
  직접적 증거
- 다른 축(T, P, RH, stoi) 외삽에서는 아직 개선 필요 — 계수 함수 형태를
  문헌 기반의 더 정교한 형태(예: 막 전도도-습도 관계의 Springer 상관식 등)로
  교체하는 것이 다음 개선 방향
- R_ohm이 CFD 데이터로 크게 밀려난 것(0.0235→0.1434)은 두 데이터 소스의
  조건 불일치 가능성을 시사하므로 확인 필요
