# IMT & PEMFC Lab Website

A single-page website for the Intelligent Manufacturing Technology (IMT) &
PEMFC Laboratory, Future & Automotive Engineering Department, Kongju
National University (Cheonan Campus).

## Contents

- `index.html` — the entire site (markup, styles, and a small canvas
  animation script) in one file
- `images/` — team and gallery photos (currently SVG placeholders)

## Viewing locally

No build step is required. Open `index.html` directly in a browser, or serve
the folder with any static file server, e.g.:

```bash
npx serve .
```

## Replacing placeholder images

The team and gallery photos under `images/` are placeholders. Drop real
images into `images/team/` or `images/gallery/` using the same filenames to
replace them.
